# BLAIR

A small frontend project built from scratch to track my dog's medication and meals using NFC tags.

BLAIR is my dog, and the project started from a simple idea: scan the pill container, register the medication, then scan the food container and confirm the meal.

## Features

- Two NFC entry points: medication and food
- Medication must be registered before a meal
- Morning and night feeding sessions
- Relative timestamps such as `34 min ago` or `2 h 15 min ago`
- Meal and medication history
- Basic feeding statistics
- Data persistence with `localStorage`
- Mobile-first responsive interface
- Static deployment with Vercel

## Built From Scratch

The project uses only:

- HTML
- CSS
- Vanilla JavaScript
- Browser APIs

No frontend framework or backend is used.

The main purpose of the project is to learn how to build a stateful frontend from scratch, including UI state, local persistence, date and time logic, validation, and basic data visualization.

## Structure
